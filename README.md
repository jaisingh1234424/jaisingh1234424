## 🚀 Featured Projects

### 1. Freshico Hypermarket Home Delivery Analysis

**Tools:** MS Excel, Formulas, Charts

- Analysed 22,823 home-delivery orders and 3,750 customers.
- Cleaned and combined two datasets.
- Created helper columns for delivery slots and weekdays.
- Used COUNTIFS, SUMIFS and AVERAGEIFS for KPI analysis.
- Identified a 99.55% order completion rate.
- Analysed customer lifetime value, delivery time and discounts.

### 2. Airline Database Analysis

**Tools:** SQL

- Analysed an 8-table airline database.
- Worked with flights, tickets, bookings, airports and passengers.
- Used SQL Joins, CASE statements and aggregations.
- Applied Window Functions to answer business questions.

### 3. Northwind Database Analysis

**Tools:** SQL

- Analysed a 12-table trading database.
- Explored sales, customers, products and orders.
- Used multi-table Joins and CASE statements.
- Applied Window Functions for ranking and running totals.

### 4. Magnus Works Business Dashboard

**Tools:** Power BI

- Analysed approximately 56,000 sales lines and 25,000 orders.
- Cleaned and modelled data.
- Built interactive charts, visuals and filters.
- Analysed $7.98M revenue and $2.22M profit.
- Identified a 27.8% profit margin and 2.2% return rate.
- Analysed category, country and yearly revenue performance.

### 5. Super Bowl Data Analysis

**Tools:** Python, Pandas, Matplotlib, Seaborn

- Analysed datasets covering 52 Super Bowl games and 134 halftime performances.
- Combined game and television viewership datasets.
- Used Pandas, groupby and filtering for data analysis.
- Created histograms, regression plots and line charts.
- Explored viewership trends, scoring differences and advertising costs.
